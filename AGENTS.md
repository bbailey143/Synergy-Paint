# Repository guidance

Synergy-Paint is a new repository for integrating access to desktop AI models
Claude and Codex. The project does not yet define an application stack or
development commands.

- Review the existing files before choosing tools, dependencies, or a project
  structure.
- Keep changes focused and document any setup or verification commands that are
  introduced.
- Run the checks relevant to a change; do not assume a build or test command
  exists.
