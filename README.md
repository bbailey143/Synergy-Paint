# Synergy-Paint

Repository for integrating access to desktop AI models Claude and Codex.

## Working with the repository

Clone this repository and open its folder as a project in your Claude or Codex
desktop app. `CLAUDE.md` provides Claude-specific project guidance, and
`AGENTS.md` provides shared guidance for Codex and other coding agents.

This repository is an initial scaffold; it does not yet include an application
or define build and test commands.
