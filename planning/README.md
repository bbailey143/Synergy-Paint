# Planning stage: Synergies

**Live, shared mind map:** https://claude.ai/artifact/EhFfMKkwkfVGbEtqfDfX4w

## The idea

Synergy Paint does not get a separate "oil engine", "watercolor engine" and so on.
Instead there is **one set of Shared Laws** (flow, pigment settling, drying, soaking in,
rubbing off, smearing, height, light and color, gravity, time), and every material is a
**Synergy**: a recipe of property values those laws read.

Change a few numbers and watercolor becomes gouache. Change a few more and it becomes acrylic.

## Branches on the map

| Branch | What it holds |
| --- | --- |
| The Shared Laws | The rules every material obeys. Synergies only set the numbers. |
| Pigment | The colored particles, shared by wet and dry media. |
| Fluid Medium | Watercolor, gouache, acrylic, oil, ink, alcohol ink, egg tempera (+ encaustic, fresco). |
| Solid Medium | Graphite, charcoal, colored pencil, crayon, oil pastel, soft pastel (+ Conté). |
| Substrate | Papers, canvases, panels, Yupo, rice paper. |
| Instrument | Brushes, knives, nibs, felt tips, plus sponges, erasers and stumps. |
| Bundles | The fuzzy middle: pencils, markers, pens. An Instrument locked to a Medium. |
| Additives | Linseed oil, solvent, retarder, gel medium, ox gall, masking fluid, fixative. |
| Environment | Humidity, temperature, easel tilt, time speed. |
| Interactions | Where Synergies meet: medium × substrate, instrument × medium, and so on. |
| Build Order | Simplest laws first: paper + graphite → dry media → thin fluids → opaque → thick paint → bundles. |
| Open Questions | Decisions still to make together. |
